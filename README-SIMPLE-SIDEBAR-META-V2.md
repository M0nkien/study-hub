# StudyHub V2 – jednoduchý sidebar + informácie o verzii

## Čo sa zmenilo

Ľavý panel zostáva zjednodušený a obsahuje iba:

- Domov
- Predmety
- Flashcards
- Výsledky
- Roadmapa
- Podpora

Do spodnej časti sidebaru bol vrátený informačný blok z predchádzajúcej verzie:

- Verzia stránky: **V2**
- Posledná aktualizácia: **09/2026**
- Stav: **Všetko funguje správne**

Jednotlivé predmety zostávajú dostupné cez stránku **Predmety** a tmavý dashboard dizajn sa nemení.

## Upravené súbory

- `script/v2.js` – obnovený spodný informačný panel sidebaru
- HTML stránky – aktualizovaný cache parameter pre `v2.css` a `v2.js`

## Nahratie

Skopíruj obsah priečinka `studyhub/` do svojho projektu a potvrď prepísanie súborov.
